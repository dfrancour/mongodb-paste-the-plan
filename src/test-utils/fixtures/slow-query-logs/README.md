# Slow-query log fixtures

Real `Slow query` log lines used by the Slow Query Explorer tests. None of
these contain proprietary data.

- `6.0/standalone/` — generated by the test-fixtures workload in
  [mongodb-slow-query-log-generator](https://github.com/dfrancour/mongodb-slow-query-log-generator) against a local `mongod` 6.0.26
  with `--slowms 0`. `slow-queries.jsonl` holds only slow-query entries;
  `mixed-messages.jsonl` interleaves other log messages for skip-and-report
  tests.
- `8.0/docs-examples/` — entries adapted from the MongoDB documentation
  ("Log Messages" reference and MongoDB 8.0 release notes) to cover fields the
  local server cannot emit: `workingMillis`, `queues`, `queryShapeHash`,
  `planCacheShapeHash`, `cpuNanos`, `storage.data`.

To add a version, run the generator's `src/test-fixtures/run.sh <version>`
against that `mongod` and copy the output here.

The example log the app serves (`public/examples/slow-query-log.jsonl`) is a
different capture from the same generator (`src/example-log/run.sh`): a
multi-tenant helpdesk workload at the server's default 100 ms threshold
against an 8.x `mongod`, so it reads like a production slow log rather than a
trace of every operation. `src/lib/slow-query/exampleLog.test.ts` guards it.
